# sistema-control-rescate-adopcion-animal
Diseño de arquitectura lógica para la gestión de rescates y adopciones de animales.
## Actores principales

- Ciudadano o reportante
- Voluntario
- Veterinario
- Administrador del refugio

## Patrones de diseño

- MVC
- Singleton
- Factory Method
- Observer
- Repository

## Flujo de trabajo

El proyecto utiliza Gitflow mediante las ramas master, develop y feature.
