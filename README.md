# sistema-control-rescate-adopcion-animal
Diseño de arquitectura lógica para la gestión de rescates y adopciones de animales.
## Páginas desarrolladas

- `src/web/index.html`: página principal del sistema.
- `src/web/reportar.html`: formulario para registrar rescates.
- `src/web/rescates.html`: listado de casos registrados.
- `src/web/assets/img/logo-refugio.svg`: logotipo utilizado en las páginas.

## Tecnologías utilizadas

- HTML5.
- Git y GitHub.
- Visual Studio Code.
- GitHub Desktop.
- Live Server.
